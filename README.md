# 🌊 Lavanderia Aquasec

Site desenvolvido para a **Lavanderia Aquasec**, um negócio familiar da comunidade local que não possuía presença online. Este projeto foi realizado como parte do PEX (Projeto de Extensão) do curso de **Análise e Desenvolvimento de Sistemas** com o objetivo de apoiar pequenos empreendedores na transformação digital.

## 💻 Acesse o site
➡️ [Clique aqui para acessar o site](https://probstella.github.io/lavanderiaaquasec/)

---

## 🚀 Funcionalidades

- ✅ Página de serviços
- ✅ Formulário de contato
- ✅ Mapa de localização integrado
- ✅ Botões de rolagem suave
- ✅ Acessibilidade para pessoas surdas
- ✅ Design responsivo (mobile, tablet e desktop)
- 🚧 **Em desenvolvimento:** integração de chatbot
